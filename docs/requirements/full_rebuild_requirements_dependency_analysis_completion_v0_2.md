# 完成版要求依存関係分析 完了記録 v0.2

完成版 Junior Study Trainer の全要求について、
要求間の直接依存関係を整理し、
未知ID、自己依存、リリース区分逆転、
未整理要求および循環依存を横断的に検査した

技術方式、DB、API、画面構成などの実装方式を
確定するものではない。

## 3. 意図的に直接依存を持たない要求

- `REQ-CATALOG-AUTHORITY-002`
  - 学校教科における根拠資料区分を定める、独立した最上流原則。
- `REQ-ID-002`
  - コードと内部IDの分離を定める、独立した最上流原則。
- `REQ-ID-008`
  - ID形式の確定時期を定める要求であり、他のID要求と並列のため直接依存を持たない。

これらは依存関係の整理漏れではなく、
独立した最上流原則または他要求と並列の原則として
直接依存を設定しない。

## 4. 循環依存の解消結果

初回の最終監査で確認された7個・21要求の循環を、
要求文と依存理由を個別に確認したうえで解消した。

### SCC 1

- 対象: `REQ-BACKUP-001 / REQ-DATA-OUTPUT-004`
- 判定: バックアップ出力機能から、通常保存とは独立した復元手段への依存を維持した。

### SCC 2

- 対象: `REQ-CATALOG-001 / REQ-CATALOG-003 / REQ-CATALOG-004 / REQ-CATALOG-005 / REQ-CONTENT-007`
- 判定: 分類構造の上位原則から具体的カタログ方式へ戻る逆向き依存を削除した。

### SCC 3

- 対象: `REQ-CYCLE-001 / REQ-MASTERY-001`
- 判定: 長期の弱点・定着管理から、比較対象である短期周回管理への依存を維持した。

### SCC 4

- 対象: `REQ-CYCLE-010 / REQ-MASTERY-002 / REQ-MODE-004 / REQ-PROGRESS-005 / REQ-PROGRESS-006`
- 判定: 一時的再挑戦と継続周回の区別から弱点練習モードへの不要な依存を削除した。

### SCC 5

- 対象: `REQ-EVENT-006 / REQ-LEARNING-STATE-006 / REQ-MASTERY-010`
- 判定: 変更されない回答イベントから、派生情報へ向かう逆方向依存を削除した。

### SCC 6

- 対象: `REQ-EXAM-PART-002 / REQ-TIMER-003`
- 判定: 本番形式タイマーから試験区分の制限時間を参照する方向を維持した。

### SCC 7

- 対象: `REQ-PLAYER-008 / REQ-TIME-003`
- 判定: 停止時間除外規則から一時停止・再開操作を参照する方向を維持した。

解消後の依存グラフには循環SCCおよび循環ノードが
存在しない。
