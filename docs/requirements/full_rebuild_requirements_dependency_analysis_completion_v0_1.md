# 完成版要求依存関係分析 完了記録 v0.1

## 1. 目的

完成版 Junior Study Trainer の要求一覧について、
要求間の直接依存関係を整理し、
重複、未知ID、自己依存、リリース区分逆転、
循環および未整理要求を横断的に検査した結果を記録する。

本書は要求依存関係分析の完了記録であり、
技術方式、DB、API、画面構成などの実装方式を
確定するものではない。

## 3. 意図的に直接依存を持たない要求

- `REQ-CATALOG-AUTHORITY-002`
  - 学校教科における根拠資料の区分を定める、他要求へ依存しない最上流原則。
- `REQ-ID-002`
  - コードと内部IDの分離を定める、他要求へ依存しない最上流原則。
- `REQ-ID-008`
  - ID形式の確定時期を定める要求であり、他のID要求と並列のため直接依存を持たない。

これらは依存関係の整理漏れではなく、
独立した最上流原則または他要求と並列の原則として
直接依存を設定しない。

設計上の責務分離、派生データと事実データの分離、
または依存方向の詳細化によって解消可能かを検討する。
