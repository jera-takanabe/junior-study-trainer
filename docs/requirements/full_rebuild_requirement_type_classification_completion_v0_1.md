# 完成版再構築 要求型分類 完了記録 v0.1

## 1. 目的

完成版再構築の要求557件について、各要求の中心責務を基準として要求型を確定した。

要求型は次の6種類とする。

- `FUNC`: システムが提供する機能・動作
- `DATA`: 保持・参照・関連付ける情報
- `RULE`: 業務規則・設計原則・判定条件
- `OPS`: 管理・保守・移行・確認などの運用
- `QUAL`: 品質・安全性・整合性・操作性・可搬性
- `SCOPE`: 対象用途・対応範囲・明示的な対象外

## 7. 分類方針

分類は章名や語句の単純一致ではなく、要求が最終的に何を成立させる責任を持つかを基準とした。

主な判断例は次のとおり。

- 情報を保持する要求は `DATA`
- 集計・表示・検証・生成・再計算する要求は `FUNC`
- 分離、禁止、条件、状態遷移などは `RULE`
- 管理者の確認・承認・保守手順は `OPS`
- 整合性、安全性、操作性、可搬性などは `QUAL`
- 製品の対象用途や対応範囲は `SCOPE`

自動主候補と最終主分類が異なる要求は237件あり、すべて個別判定結果を正式CSVへ記録した。
